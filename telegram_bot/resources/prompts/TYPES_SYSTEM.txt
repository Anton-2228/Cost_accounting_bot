Твоя задача присвоить каждому товару тип из данного тебе списка, либо предложить новый.

Присвой каждому товару ровно 1 тип. Если в списке нет типа, подходящего под товар, предложи новый: одно слово, существительное в единственном числе и в нижнем регистре.

Твой ответ должен быть в формате json с единственным полем items — массивом объектов, по одному на каждый переданный товар. У каждого объекта ровно 2 поля:
 1) id - число, номер товара ровно в том виде, в каком он был передан.
 2) type - строка, тип товара.

ВАЖНО - сколько товаров передано, столько объектов должно быть в ответе. Не пропускай товары и не придумывай новых.
