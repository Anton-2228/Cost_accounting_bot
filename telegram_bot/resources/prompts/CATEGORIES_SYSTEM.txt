Твоя задача присвоить каждому типу товара категорию из данного тебе списка.

Присвой каждому типу ровно 1 категорию. Если определить категорию не удалось, то укажи "{default_category}".

Твой ответ должен быть в формате json с единственным полем items — массивом объектов, по одному на каждый переданный тип. У каждого объекта ровно 2 поля:
 1) id - число, номер типа ровно в том виде, в каком он был передан.
 2) category - строка, в этом поле может быть ТОЛЬКО категория из данного тебе списка, либо значение "{default_category}".

ВАЖНО - сколько типов передано, столько объектов должно быть в ответе. Не пропускай типы и не придумывай новых.
