Команды

/menu — меню: ссылка на таблицу, синхронизация, доступ по почте, отвязка, настройки
/help — эта справка
/start — вход; им же можно прервать начатый диалог

/add сумма категория счёт пометка
    Пример: /add 500 еда карта обед в столовой
/del id
    Без id удалю последнюю операцию периода.

/add_trans сумма откуда куда пометка
    Пример: /add_trans 1000 наличные карта отложил
/del_trans id
    Без id удалю последний перевод периода.

/check — разобрать чек, отсканированный в приложении
    Показываю позиции, предлагаю типы и категории, спрашиваю счёт.
    Поправить: строками вида «1,3 - молочка».
    Отложить чек, удалить его или выйти из разбора — кнопками под сообщением.
